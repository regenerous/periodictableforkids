# Changelog

## [0.3.0] - 2026-08-16

- Simplified the 3D atom controls to spin, zoom, and reset.
- Shifted electron orbits outward so the innermost electrons stay clear of the nucleus.
- Added a confirmed Reset Stickers action to the Sticker Book.
- Removed discovery stars from element tiles for a cleaner table.
- Made the color-cousin legend visible by default and removed two unused filter choices.
- Expanded the full-window confetti celebration to every successful craft.
- Enlarged crafting-clue text in the table and Molecule Maker.
- Increased the contrast of puzzle-piece recipe markers with pink borders and white badges.
- Added a crafting transformation that combines ingredients into a spinnable 3D atom-team model.
- Enlarged element tiles and added readable two-line element names.
- Rebalanced the desktop explorer so the full periodic table fits beside a narrower atom panel.
- Added a Craft another button that restores the crafting table after a discovery.
- Spaced crafted atoms farther apart so their bonds are easier to see.
- Moved recipe-partner borders inside their tiles so neighboring highlights never overlap.
- Refreshed the README hero image to match the latest interface.

## [0.2.0] - 2026-08-16

- Renamed the experience to Periodic Table for Kids.
- Added clickable color-cousin filters with kid-friendly hover and focus explanations.
- Added recipe-partner clues directly to the periodic table.
- Redesigned Molecule Maker as a nine-slot crafting table with animated ingredient meters.
- Added a draggable and zoomable 3D atom model.
- Improved selection of natural and premium device voices.

## [0.1.0] - 2026-08-16

- Added the complete 118-element Bubble Lab periodic table.
- Added animated electron-shell models and spoken element introductions.
- Added playful illustrated examples for every element.
- Added an atom-versus-molecule visual lesson.
- Added the Molecule Maker with 10 discoverable atom recipes.
- Added persistent element stickers, recipe stickers, and achievement badges.
- Added iPad-responsive layouts, large touch targets, reduced-motion support, and GitHub Pages deployment.
- Added a graphic-rich, cross-platform README with visual walkthroughs of every activity.
